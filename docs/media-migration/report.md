## Verification and decisions

- Downloaded actual response bodies for all 36 references. File signatures/dimensions were checked with image-size; all 31 unique images were fully decoded with Sharp in temporary tooling outside the repository and inspected in a contact sheet. Sharp is not a project dependency.
- Added image-size as one development-only dependency for repeatable offline image format/dimension checks; no runtime dependency was added.
- SHA-256 deduplication saves 1,138,838 bytes. Every original identity, intended path, position, group caption and adjacent caption remains in the manifest; actual paths are recorded separately. Descriptive alt text is based on the retrieved images and does not replace original captions.
- The original inventory is pinned in inventory.json. The verifier compares all original IDs and source/position/caption fields, checks status, existence, size, dimensions, signature, hash and deduplication targets. Missing or inaccessible statuses can be recorded but fail verification until resolved.
- Assets live under public/assets/content so Vite copies them without recompression even before a rendering component imports them. Use import.meta.env.BASE_URL + entry.publicPath for future image URLs. For this repository that yields /portfolio_website/assets/content/…; do not use the repository filesystem path as an image URL.
- Run npm run verify:media -- --dist after npm run build to confirm every production asset exists and is byte-identical. CI runs content/media verification and checks production copies.
- Source Notion references are provenance only. No expiring URL is stored in committed migration files or used at runtime. Download credentials/URLs existed only in temporary tooling outside the repository.

## Source discrepancies retained

In particular, smartsaver-transactions.png shows investment review, smartsaver-investment-review.png shows transaction history, and the Banner web Summary image/thumbnail is identical to a Passive Income Summary image. The Banner mobile Wealth image is identical to the native Wealth screenshot. These are exact source files, not substitutions. Existing relationships and captions were preserved for owner review; alt text describes the actual image. Some JPEG screenshots are small in the source (for example 1280 × 233); they were not enlarged or recompressed.
